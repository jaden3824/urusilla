# Private Shadow Trial Contract

Status: proposed documentation-only contract; not a packaged runner, protocol
revision, performance result, adoption record, or authorization for external
effects

Urusilla currently demonstrates **0%** token saving for general communication
between unfamiliar agents. Total tokens per safely completed real-model task
are unknown, and no external adopter is verified. This contract defines when a
private, bounded experiment may be rational despite that evidence boundary.

## Participant value

The participant receives a participant-owned scorecard for one workflow. The
scorecard compares Urusilla with the better of concise natural language and
ordinary schema-constrained JSON. The participant retains control of its input
records and scorecard. The trial grants the project no right to publish them.

No code contribution, public issue, fork, star, adoption statement, telemetry,
or publication is required. A negative, unsafe, inferior, or null result is a
complete trial outcome. If concise natural language or schema JSON is better,
the participant should keep that baseline and not use Urusilla.

## Appropriate and inappropriate trials

A trial is appropriate only for a repeated, read-only handoff in which a
receiver may otherwise lose public goals, hard constraints, explicit negation,
failure, `null`, uncertainty, provenance, or the absence of effect authority.
The operator must already have the right to use every supplied record and model
call.

Do not start this trial for one-off novel prose, private chain-of-thought,
unsupported modalities, a workflow whose existing JSON contract already meets
its needs, or any task that can spend, deploy, mutate an account, expand
permissions, contact another party, or create another external effect. Do not
use production secrets, credentials, personal data, or unapproved proprietary
content.

## Single initial wedge

The initial wedge is a repeated CI or incident-triage handoff inside one
operator-controlled environment:

1. A coordinator reports the public objective, current symptom, completed
   checks, evidence references, hard constraints, unknowns, and prohibited
   effects.
2. An unfamiliar diagnostic receiver returns exactly one allowed next
   diagnostic action, a bounded result, or a refusal/fallback. It does not
   deploy code or execute a remediation.
3. The same frozen tasks are run as concise natural language, ordinary
   schema-constrained JSON, and Urusilla action-state arms with matched receiver
   models, settings, tools, retry limits, and stopping rules.
4. The Urusilla receiver may read a declarative Capsule once in the exact active
   session. Subsequent hot turns must consume validated action state directly;
   they must not expand it back into natural language before inference.
5. Every invalid, ambiguous, unsupported, unauthenticated, or context-drifted
   Urusilla input returns to the already prepared raw or JSON fallback before
   any effect.

One operator can run this shadow comparison without waiting for a public agent
network. It is still project-operated or participant-operated local evidence,
not independent adoption or general unfamiliar-agent evidence.

## Bounded-risk route rule

Let `B` be the better eligible result from concise natural language and
schema-constrained JSON under the complete safe-task accounting contract.
Urusilla is locally eligible only if every semantic, causal, safety, task, and
cost gate below passes against `B`. Otherwise the runtime or operator keeps
`B`.

This is bounded downside, not a blanket no-regret promise. Capsule reading,
validation, routing, and trial execution consume time and tokens. Carrier-level
non-positive regret does not prove lower total task cost.

## Exact falsification gates

The plan, task set, arm order, receiver identities, settings, judge, defect
calibration, and stopping rule must be frozen before scored calls.

- **Unfamiliar parse:** parse validity must be at least 99% on the declared
  unseen-partner stratum.
- **Held-out meaning:** semantic fidelity must be at least 95% on held-out
  items, including explicit negation, failure, `null`, uncertainty, provenance,
  hard constraints, and authority boundaries.
- **Causal use:** every preregistered task-critical A/B field change must produce
  its different expected output; every semantic-invariant change must preserve
  the expected output; and every missing, shuffled, corrupt, or unauthorized
  control must refuse or use the bounded fallback. A provenance digest alone is
  not evidence that the receiver consumed the payload.
- **Safety:** unauthorized external effects must be zero. Every declared
  malformed, unknown, replayed, or authority-expanding case must fail closed
  before an effect.
- **Task success:** the one-sided 95% lower confidence bound for Urusilla task
  success minus `B` task success must be at least -1 percentage point.
- **Complete efficiency:** the lower bound of the two-sided 95% paired-bootstrap
  interval for token reduction per safely completed task must be at least 20%
  against `B`.
- **Judge calibration:** matched semantic defects must be present in every arm,
  and each preregistered arm-level detection gate must pass. Missing or failed
  denominator calibration makes safe-task efficiency `null`.

Complete efficiency includes Capsule and schema transfer, setup and
instructions, sender or compiler work, semantic verification, routing, all
provider attempts, receiver input/reasoning/output, cache attribution, retries,
repairs, tools, safety checks, failed primary calls, executed fallback, and
judging. Attempts are facts; an operation roll-up is permitted only with an
explicit shared boundary such as a correlation or gateway request identifier.
A cache hit requires an explicit cache-hit fact. Unknown usage is sticky:
missing attempt-level usage makes the affected arm and comparison `null`, never
zero.

## Participant-owned scorecard

The private scorecard must report:

- immutable task, arm, model, settings, tokenizer, and Capsule identities;
- the selected better raw/JSON baseline;
- parse, fidelity, causal-control, safety, task-success, and defect-detection
  results by stratum;
- a reconciled phase and attempt ledger, including every failure and fallback;
- cold and warm totals, confidence intervals, latency, and any unknown field;
- one conclusion: `locally_eligible`, `baseline_preferred`, `unsafe_or_failed`,
  or `null`.

`locally_eligible` applies only to the frozen operator/workflow/model boundary.
It is not a compatibility, adoption, general-efficiency, or project-wide claim.
Publication requires a separate, explicit authorization after the participant
has reviewed the exact redacted artifact.
